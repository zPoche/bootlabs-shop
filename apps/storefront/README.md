# @bootlabs/storefront

Official Medusa v2 Next.js storefront, taken from [medusajs/dtc-starter](https://github.com/medusajs/dtc-starter).

Bootlabs overlay in Phase 0 is limited to:

- package name `@bootlabs/storefront`
- default region `de`
- `GET /api/health`
- hero copy
- Docker `output: "standalone"`

Catalog, checkout, and branding beyond that start in Phase 1.
